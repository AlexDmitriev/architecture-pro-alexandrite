# Выбор и настройка мониторинга в системе

## Мотивация

Метрики миниторинга необходимы для того, чтобы получить объективную картину работы сервисов (в нашем случае - API подсистем, CMS и MES), понимание текущей ситуации с нагрузкой и процентом отказов систмы. Без наличия необходимых метрик мы не сможем понять источник возникающих проблем и не сможем определить варианты их решения. 


## Выбор подхода к мониторингу

1. Для MES и CMS мы будем использовать RED, как способ мониторинга различных показателей и подсистем (веб-сервисов, запросов к базам данных, очередей), тем более этот метод мониторинга допускает использование кеширования, которое мы в будущем можем внедрить.

2. Для API (MES API, CRM API, Shop API) мы будем использовать метод 4х золотых сигналов, как наиболее подходящий к API.
